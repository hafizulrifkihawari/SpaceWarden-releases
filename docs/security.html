Security & Privacy

A storage app can see your whole disk. This page tells you what SpaceWarden does with that access, so you can decide if you trust it.

In short

  • No account. You do not sign in.
  • No analytics, no telemetry and no crash reports.
  • No upload. All processing is on your Mac.
  • Passwords, keys and private messages are never scanned or read.
  • The app connects to the internet only when you select Check for Updates.

What SpaceWarden reads

To measure space, SpaceWarden reads the names, sizes and dates of your files. It reads the contents of a file only when you preview it or search for duplicates. This also happens only on your Mac.

SpaceWarden never scans or reads these items. No setting can change this:

  • Keychains and password managers.
  • SSH and GPG keys.
  • Cloud and developer credentials, for example ~/.aws and ~/.kube.
  • The macOS privacy database.

Mail, Messages and other private data are off by default.

What SpaceWarden stores

SpaceWarden can remember the last scan, so it opens fast. The file holds file names and sizes, never contents. It is in ~/Library/Application Support/SpaceWarden, and only your user account can read it. To turn this off or delete the file, open Settings → Privacy and use Remember the last scan on this Mac or Delete Saved Scan.

When SpaceWarden connects

SpaceWarden connects only when you select SpaceWarden → Check for Updates…. Then it makes one HTTPS request to raw.githubusercontent.com and reads the small file update.json from this project. It sends no information about you or your files. It never accepts connections.

If a new version is available, SpaceWarden shows a link to the release page on GitHub. It never downloads or installs an update by itself. You choose when to update.

This website has no analytics or trackers. GitHub hosts it.

macOS permissions

Full Disk AccessOptional. SpaceWarden never asks for it by itself. Without it, the scan skips iCloud Drive, cloud storage folders, the data of other apps and the Trash. Every feature still works. To count these folders too, turn it on in Settings → Privacy.
Automation (Finder)Asked only when you uninstall an app that the system owns. SpaceWarden then asks Finder to move that app to the Trash.

SpaceWarden has no helper that runs as an administrator.

The beta and the macOS warning

SpaceWarden is an early beta. It is not signed and notarized through Apple's Developer ID system yet, so macOS shows a security warning. If you downloaded the app from the official GitHub release, check the checksum below. Then open the app with Open Anyway.

  1. Open SpaceWarden from Applications. macOS shows a warning. Click Done.
  2. Open System Settings → Privacy & Security.
  3. Scroll to Security. Next to the SpaceWarden message, click Open Anyway.
  4. Enter your password, then click Open Anyway again.

You do this one time for each version. Do not turn off Gatekeeper. SpaceWarden never asks you to do that.

In the beta, macOS forgets Full Disk Access after each update, because each beta version has a new signature. If you use Full Disk Access, turn it on again after an update.

Check the download

Each release page shows a SHA-256 checksum of SpaceWarden.dmg. The file SpaceWarden.dmg.sha256 on the release page holds the same value. To make sure that you have the official file:

  1. Open Terminal.
  2. Type this command, then press Return: 
    shasum -a 256 ~/Downloads/SpaceWarden.dmg
  3. Compare the result with the checksum on the release page.

If the two values are not the same, do not open the file. Delete it, and download it again from the official release page.

Report a problem

If you find a security or privacy problem, open an issue on GitHub. Do not put your file names or other private data in the issue.
