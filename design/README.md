# Design sources

  `rsvg-convert -w 1200 -h 630 design/og.svg -o docs/assets/og.png`.
- `docs/assets/app-window.svg` is an illustration of the Overview, not a screenshot. Replace it
  with a real screenshot of a test folder with no private file names.
